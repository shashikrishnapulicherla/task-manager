# Task Manager App

A responsive task manager built with HTML, CSS and vanilla JavaScript.

## Features
- Create, read, update and delete tasks
- Priority levels: High, Medium, Low (colour-coded, sorted by priority)
- Mark tasks done / undone, filter by priority
- Data persisted in the browser using `localStorage`
- Responsive layout for mobile and desktop

## Setup
No build step or dependencies needed.

1. Clone the repository: `git clone https://github.com/shashikrishnapulicherla/task-manager.git`
2. Open the `task-manager` folder.
3. Double-click `index.html` to open it in your browser.

## Project structure
- `index.html` - page markup
- `style.css` - responsive styles
- `app.js` - CRUD logic, persistence and rendering
